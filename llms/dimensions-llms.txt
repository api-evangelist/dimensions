# Dimensions

> Dimensions is a research data platform from Digital Science covering 430M+ interconnected
> research records — publications, grants, patents, clinical trials, datasets, policy documents,
> researchers and organizations. The Dimensions Analytics API exposes that graph through the
> Dimensions Search Language (DSL): a subscription-only, read-only HTTP surface with exactly two
> endpoints — one to exchange an API key for a ~2 hour JWT, one to POST a DSL query. Digital
> Science also publishes a first-party MCP server that projects the DSL as 27 agent tools.

Provenance: this file was GENERATED by API Evangelist on 2026-09-06 from the Dimensions
public documentation and this repository's artifacts. Dimensions does not publish an llms.txt
at https://docs.dimensions.ai/llms.txt or https://www.dimensions.ai/llms.txt (both 404 on
2026-09-06). It is not an official Dimensions document.

Key facts an agent should know before calling:
- Access is by institutional subscription only. There is no free tier, no self-serve signup,
  and no published pricing. Free access exists for eligible scientometric research projects.
- 30 requests per IP address per minute, edge-enforced, not modifiable, and NOT signalled:
  the API returns neither Retry-After nor X-RateLimit-* headers. Self-throttle.
- Max 1,000 rows per call; max 50,000 records per search via limit/skip; max 1,000 facet buckets.
- The auth header keyword is `JWT`, not `Bearer`.
- Bulk extraction, local mirroring of Dimensions data, and use for model training are
  prohibited by the Reasonable Use policy.

## Agents and MCP

- [Dimensions Analytics MCP documentation](https://docs.dimensions.ai/dsl/mcp.html)
- [Dimensions Analytics MCP source (MIT)](https://github.com/digital-science/dimensions-analytics-mcp)
- [Tool reference — 27 tools](https://github.com/digital-science/dimensions-analytics-mcp/blob/main/docs/USAGE.md#all-mcp-tools)
- [MCP reference — env vars, rate limits, schema cache](https://github.com/digital-science/dimensions-analytics-mcp/blob/main/docs/REFERENCE.md)
- Install (local stdio, Node 20+): `npx -y @digital-science-dsl/dimensions-analytics-mcp`
  with `DIMENSIONS_API_KEY` set. A hosted URL+token option is announced as coming soon and is
  NOT yet available.
- A separate OAuth-gated remote MCP endpoint runs on the marketing site at
  https://www.dimensions.ai/wp-json/mcp/mcp-oauth-server (RFC 9728 metadata at
  https://www.dimensions.ai/.well-known/oauth-protected-resource, scope `mcp`, PKCE S256).
